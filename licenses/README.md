# Сторонний runtime

В локальную `.app` копируется неизменённый Bun 1.3.12 из установленного runtime.
Его исходники и инструкции пересборки доступны в
[oven-sh/bun, bun-v1.3.12](https://github.com/oven-sh/bun/tree/bun-v1.3.12).
Файл [Bun-LICENSE.md](Bun-LICENSE.md) — уведомление из этой версии upstream.
Нативная панель и JavaScript приложения не линкуются с JavaScriptCore напрямую:
launcher запускает Bun отдельным процессом. Runtime можно заменить совместимой
пересобранной версией и заново подписать локальный bundle.

Публичная дистрибуция и подготовка полного набора лицензионных материалов для
публикуемых бинарников в эту задачу не входят. Репозиторий приватный, сборки
не загружаются в GitHub releases или artifacts.
